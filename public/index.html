🧠 UNet-SR Architecture & Formulation

Designed specifically for SEMICON India Hackathon 2026 Problem Statement 1: AI-Based Restoration of Degraded Images for Semiconductor Inspection.

// 1. Degradation Model Formulation
y = D( x · (1 + η_s) ) + η_g
where η_s ~ N(0, σ_s²) (speckle), D = 2x downsampling, η_g ~ N(0, σ_g²)

// 2. Global Residual Super-Resolution
x̂ = Bilinear(y) + Δ
where Δ is the high-frequency residual predicted by UNet-SR.

// 3. Composite Loss Function
L_total = λ₁·L_Charbonnier + λ₂·L_SSIM + λ₃·L_Perceptual

Key Architectural Innovations:

  • Residual Blocks with SE Attention: Squeeze-and-Excitation channel attention recalibrates feature responses to enhance edge gradients.
  • Sub-Pixel PixelShuffle Head: Reconstructs 256x256 resolution from 128x128 feature maps without checkerboard artifacts.
  • Non-Clipped Dynamic Range: Unclamped forward passes preserve physical electron detector count distributions.
